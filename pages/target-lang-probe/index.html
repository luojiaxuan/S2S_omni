目标语言扩展探针

MiniCPM-o 4.5 双工同传模型从 en→zh 扩到其他目标语言时, 瓶颈在哪一环. FLEURS 14 种语言 × 100 句平行句子, 每一环单独测.

结论

  1. 数据端不是瓶颈. MOSS-TTS-v1.5 合成的目标语音, 14 种语言的转写误差都不高于 FLEURS 真人录音.
  2. talker 的语音 token 空间对 8 种语言够用 (日, 韩, 德, 法, 西, 意, 葡, 俄): 合成语音往返后, 超出中英对照不到 1 个点. 阿拉伯语, 越南语, 土耳其语不够; 印地语换同语种音色后接近够用.
  3. talker 本身必须按语言训练. 基座模型照着标准文本朗读, 拉丁字母语言 21% 到 48% 错误率, 非拉丁字母语言 93% 以上.
  4. 所有候选语言都比中文费时. 同一句话, 中文的有声时长是英语的 0.94 倍, 其余语言 1.05 到 1.31 倍.
  5. 建议先做德语: token 空间够用, ACL 60/60 有 en→de 参考译文, 打分器已支持德语, 基座 talker 已能部分读德语.

talker 的语音 token 空间: 往返损失超出中英对照多少

语音 → S3 码 (talker 的训练标签) → 模型自带解码器, 按双工运行时的流式窗口解码, 再用 Whisper large-v3 转写. 横轴是该语言往返后误差的增量减去对照语言 (WER 语言对英语, CER 语言对中文) 的增量, 单位是百分点, 线段是 95% 区间. 跨过 0 即不比现役语言差. talker 学的是合成语音, 所以蓝点是判据.

口径

  • 样本: FLEURS test 中 14 种语言共有的 139 句里随机抽 100 句, 各语言是同一批句子; 基座朗读只用前 50 句.
  • 转写: Whisper large-v3, 强制语言. 归一化后算 CER (中日韩) 或 WER; 每句错误数封顶在参考长度, 生成失败按整句错误计.
  • 区间: 按句子联合自助抽样 2000 次. 往返的对照组本身也有损失 (中文 CER +2.1, 英语 WER +0.6), 现役中文系统本来就承受它.
  • 音色: 主结果用管线固定的中文音色; 换成同语种音色的对照只改变印地语的判断.
  • 未做: 每语言多个音色, 母语者听辨, 第二个独立识别器. 德语与俄语处在边界, 这几项可能改变它们的判断.
